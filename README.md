# Reef Rush 🌊🐠

**Reef Rush** is a browser-based ocean arcade project created for portfolio presentation and GitHub Pages.

## Live Demo

https://laurandreea10.github.io/Reef-Rush/

## Overview

Reef Rush is designed as a fast, colorful underwater experience with reef-inspired visuals, arcade movement and a playful ocean atmosphere.

It fits well as a creative front-end project because it combines visual design, game-style interaction and responsive browser delivery.

## Highlights

- Ocean / reef visual theme
- Arcade-style gameplay concept
- Colorful underwater mood
- Responsive browser layout
- Portfolio-ready presentation
- Static deployment through GitHub Pages

## Possible Game Features

The project can be expanded with:

- collectible pearls or shells;
- coral obstacles;
- boost bubbles;
- score and high score tracking;
- levels or missions;
- mobile touch controls;
- sound effects;
- achievements and skins.

## Run Locally

Clone the repository:

```bash
git clone https://github.com/LaurAndreea10/Reef-Rush.git
cd Reef-Rush
```

Open `index.html` in your browser.

No install step is required if the project uses plain HTML, CSS and JavaScript.
